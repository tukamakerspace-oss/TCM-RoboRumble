
# TCM-RoboRumble

Welcome to our official project repository for Robo Rumble 2026. This repository contains all of our engineering documentation, remote control configurations, and hardware logs.

## Repository Structure
* /src — Contains manual RC control mapping and motor driver test code.
* /docs — Contains our engineering notes and submission files.
* FQA_Attendance_Log.md — Our official Facilitator Q&A attendance logbook.

## Build & RC Software Stack
* Microcontroller / Receiver: ESP32 and REV control hub
* RC Controller: PS4
* Key Components: DC motors, Battery, Mechanical parts

## How to Run the Code
1. Open the /src folder to view our manual driver-input channel configurations.
2. Upload the control mapping script to the microcontroller via USB.
3. Power on the transmitter, connect the robot battery, and test the wireless binding.
